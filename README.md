# ScrapeRack

Scale local scraping and web automation workloads across self-hosted infrastructure with minimal changes.

ScrapeRack is an early-stage workload platform for ephemeral scraping, browser automation, and general Python execution. It will provide a Python SDK backed by a Dockerized execution platform using Ray.

## Initial scope

- Python workload SDK
- Docker-based execution
- Distributed scheduling through Ray
- Automated tests and GitHub Actions
- Reproducible development and deployment workflows

Kubernetes support is planned for a later stage, after the Docker-based architecture is proven.
